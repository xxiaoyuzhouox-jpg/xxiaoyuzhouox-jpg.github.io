# 象昇办公室 · 手机与电脑演示

演示地址：https://xxiaoyuzhouox-jpg.github.io/xiangsheng-office/index.html

本目录发布在现有仓库的 xiangsheng-office 子目录，保留根目录的原应用。请勿把本目录的 index.html 覆盖到仓库根目录。

手机：方向按钮行走、单指拖动视角、点击展品；平面导览可快速到达各房间、鱼缸和品牌墙。电脑：WASD / 方向键行走，拖动转向，E 查看展品或开关杜总办公室门。

本次新增柜式双乌龟缸、玻璃隔断、第九把会议椅、130 英寸落地电视、尹总办公室茶海及沙发，以及按尺寸制作的象昇品牌墙。杜总办公室默认关门。入口仍为电梯出口。

文件：app.js（布局与交互）、office-details.js（新增模型）、exhibition-room.js（展厅）、space-config.js（产品与灯光配置）。全部前端依赖随项目提供，无需 GPT 登录或后台服务。

品牌墙使用用户提供的参考图标识，部分被遮挡格子暂复用清晰标识。地毯使用 Poly Haven CC0 材质，Three.js 使用 MIT 许可。详见 assets/ATTRIBUTION.md 和 vendor/THREE-LICENSE.txt。
